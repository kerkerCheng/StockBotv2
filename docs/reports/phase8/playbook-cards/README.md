# 劇本卡（Phase 8 第一輪）——欄位定義與規則

> 版本：**欄位 v1（2026-11-22 凍結，先於任何一張卡）**｜載體：[設計稿第三版](../../../brainstorms/2026-11-21-playbook-replay-design-v3.md)檔尾 2026-11-22 修正案（使用者「簽」）
> 這是**描述型**的劇本庫：人挑的段、已看過的股價、小樣本。它能說「這一段裡出現過這句話、這個數」，不能說「這個訊號有效」「會預測結束」。

## 這是什麼、不是什麼

- 一段舊劇本一張卡：某個集中的需求把量灌進一層薄的供應商，那一層怎麼起來、高點前後出現什麼、怎麼結束。
- 用來回答「現在這一檔像哪一段、像在哪、不像在哪」——**對照讀法**由研究 session 讀卡後寫進敘事與賭注句，每句指得回卡上的原句與日期。
- 不是 authority：卡上的公司名是文字加出處，不建節點、不進名冊、不進正式的圖。要把卡上的事實寫進正式的圖或當敘事的事實句，走晉升（從原始檔重走正式抽取與入圖核准）。
- 不排序、不評分、不寫目標價。卡的順序照清單編號。

## 每一格的寫法

`值｜「原句」｜發布日｜出處｜發布者`

- **原句逐字**。外文原句照原文，中文是我們的說明，不放進引號。經工具轉錄、沒有對原始檔逐字核過的，標「轉錄」。
- **發布日**是文件自己的日期（公告日、申報日、新聞稿日）；推不出就留空並列進 D2，不拿抓取日代替。
- **發布者**四種：`供應商自述`／`客戶端`／`第三方`／`機械`（由股價或財報數字算的）。供應商自述不能當「自己是瓶頸」的獨立佐證，照收、照標。
- 找不到寫「沒找到（找過：……）」；憑記憶、沒有出處的字不留在卡上。
- 價格只出現在 A6、C1（描述用）。
- 每張卡檔尾列出處清單：網址、文件自己的日期、抓取日、原始檔 sha256 前 16 碼；並印「引文程式核過 N／N」（引號裡的字在存下來的原始檔裡找得到）。原始檔住本機私有區，不進 repo；券商報告與付費內容不引。

## 欄位（v1）

**卡頭**：段｜期間｜清單上寫的「結尾的型」｜錨｜層（正式的圖上有這個節點就寫 id，沒有寫「圖上沒有」）｜代表公司｜樣本標記（原始清單／事後補＋補的規則）｜欄位版本｜做卡日｜是不是盲判

**A 怎麼起來**

| 格 | 問的是 | 型 |
|---|---|---|
| A1 | 錨的需求：買家是誰、在買什麼 | 文件（買家或第三方優先） |
| A2 | 為什麼卡在這一層：產能、認證、材料、設備交期的限制 | 文件 |
| A3 | 第一個公開訊號：缺貨、漲價、長約、預付、交期拉長的最早一句 | 文件 |
| A4 | 層的成員：當時供應的有哪幾家 | 文件 |
| A5 | 數字鐘：代表公司營收年增由負轉正（或明顯加速）的起點月；毛利率的低點季與高點季 | 機械 |
| A6 | 價格鐘：代表公司起漲月、高點月、相隔幾個月、月收盤最大倍數 | 機械 |
| A7 | 當時公司自己怎麼講：高點前一年內的一句 | 文件 |

**B 高點前後出現什麼**（定義沿用設計稿 §7.5 的 E 格）

| 格 | 問的是 | 型 |
|---|---|---|
| B1 | 同層擴產（E1）：高點前 12 個月到後 6 個月宣布擴產的家數、量、預定開出時間 | 文件 |
| B2 | 第二來源或新進者（E5）：客戶端或第三方寫出新供應商的首見日 | 文件 |
| B3 | 買家口徑轉向（E2）：買家或主要客戶的資本支出、庫存說法第一次轉保守 | 文件 |
| B4 | 買家的錢（E9）：買家的支出靠舉債或供應商融資撐的揭露 | 文件／機械 |
| B5 | 價格與合約條件：漲價停止、長約重議、預付退回、交期恢復的首見日 | 文件 |

**C 怎麼結束**

| 格 | 問的是 | 型 |
|---|---|---|
| C1 | 層回落：代表公司月收盤自高點回落 ≥ 30% 的第一個月；之後 18 個月有沒有回到前高 | 機械 |
| C2 | 公司自己怎麼解釋：回落後一年內文件寫的原因 | 文件 |
| C3 | 高點後兩年：營收、毛利率相對高點那一年 | 機械 |

**D 讀這張卡要知道的**

| 格 | 內容 |
|---|---|
| D1 | 每一格的發布日相對高點月是前幾個月、後幾個月——事前看得到的與事後才知道的分開 |
| D2 | 沒找到、量不到的格，各找過哪裡 |
| D3 | 這張卡的偏差：代表公司是不是倖存者、原句是不是只有供應商自述、段是照結尾挑的還是照起漲挑的 |

## 機械格的算法（v1；先於任何一張卡的數字寫下）

每家代表公司各算一列，不合成層線（層線是第二輪的事）。月線用還原權息的月收盤。

- **窗**：清單期間起始年的前一年 1 月，到期間結束年的後兩年 12 月（或資料末月）。
- **高點月**（A6）：清單期間內月收盤最高的月。**起漲月**：窗起點到高點月之間月收盤最低的月。**倍數**＝高點月收盤 ÷ 起漲月收盤。
- **層回落月**（C1）：高點月之後第一個月收盤 ≤ 高點 × 0.7 的月；沒有就寫「沒有回落三成」。**回到前高**：回落月之後 18 個月內月收盤曾 ≥ 高點月收盤（窗與 H16 相同）。
- **營收轉正月**（A5）：含高點月的那一段「月營收年增連續為正」的第一個月（高點月當月年增 ≤ 0 就取它之前最近的一段）。另印那一段裡年增最高的月、高點月之後第一個年增為負的月。
- **毛利率**（A5）：單季毛利率＝單季營業毛利 ÷ 單季營收（由累計數相減）。低點季＝窗起點到高點月所在季之間最低的一季；高點季＝低點季到高點季後四季之間最高的一季。
- **高點後兩年**（C3）：高點月所在年度 Y 的全年營收與全年毛利率，對 Y+1、Y+2。
- 海外公司照同一套算法，營收與毛利率取自申報文件（沒有月營收的寫季）；抓不到的格寫「量不到」。

## 開放追加

- **段可以加、欄位可以加。** 加欄位＝升欄位版本；舊卡那一格印「還沒補」，同一張比較表只收同一版本都有的格。
- **補樣本之前，先在這一節寫下：用什麼規則挑、要看哪一格。** 研究中看到一個脈絡再回頭補過往樣本去對，是檢驗它最便宜的方法——前提是樣本照規則來，不是挑記得的、剛好符合的。
- 看到脈絡之後才補的卡，卡頭標「事後」，與原始清單分開數。
- 卡上看到的規律要當依據，只有兩條路：寫成前向假說進 Phase 7 的帳往後量；或寫成某一層的反證、加碼條件並登記 watch。不得直接變成排序、門檻或預設。
