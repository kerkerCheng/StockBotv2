## 1. 為什麼（案例與次數）

- **#163**：11-13 回頭核 27 份現行敘事——**27 份都有錯**，2,857 句改 207 句。工具重放（敘事 2,023 句）只標到改掉的 135 句裡的
  56%，沒改的 1,888 句也標 27%（命中率約 13%）。事實抽樣① 11 份 8 份有錯（registration 2026-11-03 的判讀線是 30%）。
- **根因**：逐句核對在那一格的整份引用裡**猜**哪一行對得上（`rank_lines` 取前兩行），猜錯就核錯。查不準的兩種錯各有 ≥ 2 個 case：
  主詞收窄或放寬（3110.T 特種電子布、LPK.DE「主要半導體廠多數」、ATS「NVIDIA 專用」）；衍生數字與保留語氣（AXTI「三分之二」——
  原文第二季約 79%、第三季約 87%；「committed to pay」寫成「付了」）。保留語氣三種寫法在猜行的設定下量過，都只比亂猜好約 1.4 倍。
- **L18（標籤要指得回原始證據；根解是拿掉資訊落差）**：寫的人在寫的當下知道自己靠的是哪一段原文，工具事後只能猜——把那一段記下來。

## 2. 現在的邊界

- 敘事 ledger（A3，append-only）：引用掛在**格**上（一格一串 ref），沒有句子層級的原文。
- 逐句核對（`alpha/narrative/fact_check.py` 純規則＋`alpha/providers/fact_checks.py` 讀寫）：唯讀；核對紀錄 `fact_checks.jsonl`
  記句子 digest（句子＋那一格的引用），上一版核過的同一句沿用。
- ⑤「敘事還沒逐句核對」：由核對紀錄判（`fact_checks.gaps_now`）。

## 3. 提議的邊界

1. **錨點紀錄**（新、append-only、private）：`library/private/alpha/fact_anchors.jsonl`。**一列＝一個事實**：
   `anchor_id`、`company_id`、`ticker`、`created_at`、`author`、`fingerprints`（它撐的句子指紋，可以多句——同一個事實只寫一處，
   七格與故事裡講同一件事的句子都指向它）、`ref`（只收一手：`library/raw` 節錄或圖的來源文件）、`quote`（逐字原文）、
   可選 `derive`（衍生數字：`op` ∈ 封閉字彙 {ratio, share, growth, diff, sum}、`of`＝quote 裡出現的數字、`shown`＝句子寫的那個數）。
   - **句子指紋**＝`company_id`＋句子正規化文字的 sha256 前 16 碼，**不含引用**（現行 digest 含引用：一格多一條引用，那一格每一句都要
     重綁）。同一句話換版不變、錨點跟著走；句子改了指紋就變、舊錨點不再對到——要重看原文，這正是要的。
   - 錨點紀錄不是 authority：不決定候選狀態、不擋寫入。讀不懂的行照 INV-3 報出來（⑤ 那一格變「未讀到」，不是 0）。
2. **寫入命令** `python -m alpha brief-anchor <T> --spec <file>`：spec＝`[{sentences: [句子原文…], ref, quote, derive?}]`；命令自己算指紋，
   對現行那一版（敘事＋現行故事）驗證：每一句真的在、`quote` 在 `ref` 那份檔裡逐字找得到（只正規化全半形、空白、換行，不跳字）、
   `ref` 不是我們自己寫的字（節錄檔的 NOTE、改寫、Boundary 段＝`SourceLine.own`）、`derive` 的數字在 `quote` 裡——任一條不過整批拒收。
   `--draft` 印出現行版還沒錨點的事實句，各附逐句核對對到的候選行——**只給候選，`quote` 留空**（預填會變成蓋章）。
3. **比對（只印）**：`brief-check` 對有錨點的句子改拿「它自己的 `quote`」比——數字、名稱、引號、日期、限定詞，加兩種只有錨點才比得準的：
   **保留語氣**（`quote` 有 expected／may／plan／target／guidance／committed to／預計／預期／可望／計畫／目標，句子沒有）、
   **衍生數字**（`derive` 算出來的與句子寫的不符；句子有 `quote` 裡沒有的數字又沒宣告 `derive` → 照數字旗標）。
   輸出把「對錨點」與「猜行」分開印；核對紀錄多記 `anchored`（有錨點的事實句數）。
4. **事實句**＝逐句核對現在判「有沒有東西可核」的那一組：有數字、引號、英文名稱或歸屬語（某某說）；何時格與條件句（反證、錯的訊號）除外。
   同一個定義、同一個函式（L16：分類有 SSOT 就讓它跟著資料走）。
5. **⑤ 新一格「事實句還沒錨點」**：宣告可開（含前提失效）與已持有的現行敘事裡，事實句沒全部綁錨點的份數；最老天數＝那一版寫的那天。
   其餘狀態不列（②：換版時才補——寫新版的流程本身就要綁）。
6. **SKILL**：research-drain 寫敘事流程在 `brief --add`（與 `stories --add`）之後、`brief-check --record` 之前加 `brief-anchor`。

## 4. Steps

### Step A（Z2／R1）錨點紀錄與比對

- **改哪裡**：新 `alpha/narrative/anchors.py`（純規則：指紋、比對、保留語氣、衍生數字）；新 `alpha/providers/fact_anchors.py`
  （讀寫 ledger、驗 quote）；`alpha/cli.py`（`brief-anchor`；`brief-check` 印錨點比對）；`engine_b/todo_ledger.py`（⑤ 新一格）；
  `skills/research-drain/SKILL.md`；`docs/ARCHITECTURE.md`（新 ledger 一行）。
- **怎麼驗**：測試含變異（拿掉保留語氣比對 → AXTI 那一句不紅就是假的）；#163 具名的五句（3110.T、LPK.DE、ATS、AXTI 兩句）
  舊句＋正確原文寫成 fixture——五句都要被錨點比對標到，改對後的那一句不得被標。
- **修法四問**：①**顯形**，不是根除——錨點讓錯被看見（而且只在有人綁錨點時）；根除＝擋寫入，照③先量過再談。
  ②比對靠程式；「綁哪一段原文」靠寫的人——綁錯段比不出來，Step C 量這一塊。③**加一個機制**；不能用拿掉的方式：拿掉猜行，
  逐句核對就沒有原文可並排了；能拿掉的是「有錨點的句子不再猜行」——量過再決定（Step C 交你的第一題）。
  ④如果錯了，最先壞的現有資料是 ⑤ 那一格：落地當天應該是 36 左右（今天宣告可開 22＋前提失效 12＋已持有 2，一份都還沒有錨點）；
  算出 0 或未讀到就是錯——落地時去看那一格。

### Step B（研究）回填

- **範圍**：宣告可開（含前提失效）＋已持有＋11-13 回頭核的 27 份（重疊的只做一次）。查證：`python -m crons.phase_status_hint`
  「要清的」裡的「事實句還沒錨點」（同 ⑤ 那一格），加 Step C 名單。
- **每份**：`brief-anchor --draft` → 讀原文綁錨點 → `brief-check` 看錨點旗標 → 錯了照常換版（換版的句子重綁）。
- **驗收**：範圍內每份現行版的事實句全部有錨點（⑤ 那一格歸零）。

### Step C（量測）重放

- **重放 11-13 那 27 份**：沒改的句子（指紋相同）用 Step B 綁的錨點比；改掉的 135 句用「改對之後那一句」的錨點比舊句
  （錨點是為對的句子寫的，綁的時候不知道舊句錯在哪——偏差比專為重放寫錨點小）。
- **印**：改掉的被標比例（基準 56%）、沒改的被標比例（基準 27%）、命中率（基準約 13%），按錯的種類（主詞、數字、保留語氣、
  衍生數字、日期）各一列。
- **交使用者決定（量完才問，不是現在）**：①有錨點的句子是否不再猜行；②要不要談擋寫入（③ 說的量過再談）。

## 5. 驗收（數的是敘事與追蹤表）

- 重放兩個比例與命中率（Step C）。
- 現行敘事的事實句有錨點的比例——兩個分母：全部、可開＋已持有。
- 可開與已持有每份都有帶錨點的一版（⑤ 那一格 0）。

沒有一條是「幾檔通過某個 filter」（G10）。

## 6. 已知陷阱

- 節錄檔裡我們自己寫的字（NOTE、改寫、Boundary）不能當錨點——寫入時拒收（同 `SourceLine.own`）。
- 原文是簡體的 `quote` 照簡體；驗證只做正規化（全半形、空白、換行），不做語意比對。
- PDF 轉文字的斷行：`quote` 跨行時容許空白差異，不容許跳字。
- 一句撐兩個事實＝兩列錨點指向同一個指紋。
- 故事句（首屏）同樣綁；故事換版、句子改了，指紋變了要重綁。
- 指紋不含引用 → 同一家公司兩版寫了一模一樣的句子會共用錨點（同一事實、同一段原文，正是要的）。
- **（2026-11-13 Step A 落地時量到，待使用者選）只有自家來源的事實句**：⑤ 範圍 39 版的 2,719 句事實句裡，125 句所在那一格
  只引用自家（引用條數，一句可引多條：三題稽核區 87、Engine C 76、讀圖 26、其他 9）——估值脈絡、「量不到」這種系統狀態、讀圖判讀、條件句；
  一手格子裡也夾著少數判斷句（引號、「說明」）。只收一手的話它們綁不上，⑤ 永遠歸不了零（恆亮，L14④）。
  推薦：錨點多收一種「自家」——句子宣告它靠哪一份自家紀錄（讀圖、三題稽核區、Engine C 快照），讀圖要逐字對到讀圖文字；
  計數分開印（一手 X、自家 Y），⑤ 兩種都算數；手抄的估值數字換版時改 placeholder。
  替代：⑤ 只數一手格子的句子，自家格子另印一個數、不要求錨點（一手格子裡的判斷句仍綁不上）。
