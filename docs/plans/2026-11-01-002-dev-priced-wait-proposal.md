## 2. P1 等回落的重開條件

**現況**：#116 的價格叫醒＝收盤低於最後一次宣告已定價那天的收盤 → `rewrite[]` → research-drain 段 5 ⓪ 重答（一輪 LLM）。
它回答「價格動了沒」，不回答「到了沒」。

**提案**：
1. **合約**：`candidate_state` 在等回落時多一個 `reopen`——一句話 `text`，加至少一個可機械比對的值：`price_at_or_below`（研究代號的報價單位）
   或 `own_pctile_at_or_below`（三題稽核區那一條自家三年百分位）；兩個都寫不出來時 `text` 以「不適用：」開頭寫理由。
   新寫的等回落沒帶就拒收；舊紀錄照讀（沒有 `reopen`＝照 #116）。
2. **叫醒**：有 `reopen` 的等回落，叫醒條件換成（或加上，見 Q1）「收盤 ≤ 價位」或「今天的自家百分位 ≤ 那個值」；沒到只在等回落行印距離。
3. **呈現**：心跳等回落行、短版 ④、個股頁候選行印「重開：…（距 −Y%）」。
4. **判斷日**：`reopen` 進判斷鍵——改重開條件＝改判斷（與「等回落的理由改了算改判」同一條規則）；沒有 `reopen` 的現有紀錄鍵不變。
5. **SKILL**：research-drain 段 5 寫等回落時必寫重開條件與「為什麼是這個數」；⓪ 只在重開條件達成時重答。
6. **現行四份**（3081.TWO、4979.TWO、AXTI、STLTECH.NS）各補一版——研究，在本機做。

**修法四問**：①根除「等待沒有出口」（每份等回落都有一個會到的出口），叫醒本身仍是顯形；②靠程式（寫入端拒收）；
③加一個欄位——不能用拿掉的方式：拿掉 #116 會回到 #94「價格動了沒人知道」，拿掉等回落這個狀態是 P2 的事、要使用者決定；
④最先壞的現有資料：判斷鍵改了，474 版 v2 敘事的判斷日要逐筆回放比對差異 0（照 #121 的做法），在本機跑。

**會變的數字**：等回落叫醒後「重寫但狀態不變」的次數（10-31：4／4）；等回落 → 可開／不要的轉換數（今天 0）——都數敘事 ledger。
**驗收**：現行等回落每份都有重開條件（敘事 ledger）；測試含變異（拿掉比對 → 紅）；回放差異 0（待本機）。

**要使用者答的**：
- **Q1**：有重開條件的等回落，價格叫醒要「換成」重開條件，還是「加上」？推薦**換成**——10-31 四次叫醒、四次重寫、零次改變；
  「加上」保留每次回落都叫醒，重寫次數不會降。
- **Q2**：重開條件只准寫價位，還是也可以寫自家百分位？推薦**兩種都可**——成長股的百分位會隨營收長大而下降、價格不必跌。
- **Q3**：重開條件算不算 AGENTS「已定價…不設門檻」說的門檻？推薦**不算**：它是每份敘事自己寫的判斷（同反證條件），達成只叫醒重問、
  不改狀態、不給動作；系統沒有一個全體適用的數字。若你認為算，P1 不做，改提 P2。
