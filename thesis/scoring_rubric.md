# Directional Lane Memo — 評分標準 (Scoring Rubric)

> 用途：人工評分 thesis，判斷是否可升格至 Watchlist，或需退回補充資料。
> 滿分：30 分（6 個維度 × 各 1-5 分）

---

## 評分維度

### 1. 可信度 (Credibility)　/5

主張都有 Tier 1/2 一手來源支持？

| 分 | 描述 |
|---|---|
| 5 | 所有主要論點都有法說會/filing/IR 等 Tier 1 直接引用，quote 逐字出現在文件中 |
| 4 | 大部分 (≥75%) 主張有 Tier 1/2 來源；少數推斷有清楚標注 |
| 3 | 約一半主張有 Tier 1/2 來源；另一半是邏輯推斷但標注清楚 |
| 2 | 多數主張依賴推斷或 Tier 3 來源；Tier 1 引用不足 3 條 |
| 1 | 大部分或全部主張無法追溯到具體 source，或包含圖外資訊 |

**失敗閾值：< 3 → thesis 退回 U2（補充 Tier 1 文件）**

---

### 2. 瓶頸清晰度 (Chokepoint Clarity)　/5

供應鏈的 chokepoint 被準確識別並解釋？

| 分 | 描述 |
|---|---|
| 5 | 明確指出 1-2 個 chokepoint 節點/邊，有 sole_source / substitutability 數據支撐，解釋了「為什麼這個點斷了整條鏈就停」 |
| 4 | Chokepoint 清晰，但佐證稍弱（例如 substitutability 來自推斷而非文件直接數字） |
| 3 | 有指出 chokepoint 方向，但描述籠統（「X 公司很重要」但未量化集中度或解釋斷鏈機制） |
| 2 | 只有模糊的「供應緊張」或「集中度高」，沒有具體 node/edge 指向 |
| 1 | 未識別 chokepoint，或主張與圖中關係矛盾 |

---

### 3. 可證偽性 (Falsifiability)　/5

每個主要論點有具體、可觀測的 disproof_condition？

| 分 | 描述 |
|---|---|
| 5 | 每個主要論點（需求驅動 / 主瓶頸 / thesis 核心）都有具體、可觀測的 disproof 條件，且說明了「何時核查、觸發後做什麼」 |
| 4 | 所有主要論點有 disproof 條件，但「觸發後動作」或「核查頻率」缺少一項 |
| 3 | 至少 2 個主要論點有 disproof 條件，但部分條件過籠統（「如果需求下降」而非「如果 hyperscaler CapEx 指引季環比下降 > 15%」） |
| 2 | 只有 1 個 disproof 條件，或條件完全不可觀測 |
| 1 | 無 disproof 條件，或條件是套話（「如果 thesis 不成立」） |

**失敗閾值：< 3 → thesis 退回修訂 disproof_condition**

---

### 4. 洞見密度 (Insight Density)　/5

投資者看完能採取行動，還是全是已知事實？

| 分 | 描述 |
|---|---|
| 5 | 包含至少 1 個「讀完才知道、之前不明顯」的非顯性論點；leading indicator 清單可立即啟動監控 |
| 4 | 有價值的資訊整合，但缺少讓讀者「啊原來如此」的關鍵洞見 |
| 3 | 大部分內容是已知事實的重述（CPO 很重要、AI 需求強），但組織清晰 |
| 2 | 幾乎全是公開可見的共識資訊，沒有供應鏈層面的新整合 |
| 1 | 可以從任何一篇媒體報導取代 |

---

### 5. 完整性 (Completeness)　/5

7 個段落都有實質內容，且涵蓋需求/供應/技術三個視角？

| 分 | 描述 |
|---|---|
| 5 | 7 個段落全部有實質內容；同時覆蓋需求端（end_demand）、供應端（chokepoint supplier）、技術層（abstraction_level 細節）三個維度 |
| 4 | 6-7 個段落有實質內容；三個維度中有 1 個較薄 |
| 3 | 5-6 個段落有實質內容；或某個段落是套話佔位 |
| 2 | 4 個以下段落有實質內容；結構明顯不完整 |
| 1 | 段落缺失或都是佔位符 |

---

### 6. 市場差異度 (Variant Perception)　/5

Thesis 是否明確說出「市場現在信 X，本 thesis 認為 Y，催化劑 Z」？

| 分 | 描述 |
|---|---|
| 5 | 從估值（forward P/E / EV/Sales / 分析師共識）推斷了股價的隱含假設 X，明確說出本 thesis 認為的 Y，並指出可驗證的催化劑 Z |
| 4 | 有 variant perception 方向，但「股價隱含假設 X」是定性描述而非從估值數字推斷 |
| 3 | 提到「市場可能低估了…」但沒有明確的 X/Y/Z 三段式架構 |
| 2 | Variant perception 缺席，thesis 與賣方共識完全一致 |
| 1 | 不僅缺少差異，且主要論點已在廣泛報導中出現 |

**失敗閾值：< 2 → 標記為「研究素材」，不升格 Watchlist**

---

## 評分結果判斷

| 結果 | 條件 |
|---|---|
| **退回 U2（補充資料）** | 可信度 < 3 **或** 可證偽性 < 3 |
| **標記為「研究素材」（不升格）** | 市場差異度 < 2（即便其他分數高） |
| **可進入 Watchlist 升格流程** | 總分 ≥ 22/30 **且** 可信度 ≥ 3 **且** 可證偽性 ≥ 3 **且** 市場差異度 ≥ 2 |
| **升格前必做** | 財務核驗清單 5 項全部完成（客戶集中度 / 毛利率趨勢 / backlog / 稀釋 / 估值壓力）|
