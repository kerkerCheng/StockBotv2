# Detective Skill（偵探：計畫外線索組裝）

## 定位一句話

**還能漲的只剩計畫以外的東西**（使用者 2026-11-17）；共識大致等於「照計畫走」的路徑，所以偵探找的是
**兩份不同當事人的文件放在一起才看得出來**的事——買方的擴產＋賣方的合約、買賣兩方各寫一半的金額與數量、
設備商的訂單＋公司的資本支出。M0（AXTI，2026-11-18）最有用的線索就是這樣來的：AOI 的 10-Q 寫金額、雲南鍺業的公告寫片數，
合起來是 2027 年 4 吋每片約 1,080 美元——兩邊都不是 AXT 自己的文件，而共識裡沒有漲價。

偵探的回報是**研究判斷（A3）的輸入，不是判定**：LLM 可以解析與提議，不可以授權（L15）。寫進敘事的每一句由主 session
核過原文、照既有寫入流程落地；候選狀態、判斷、門都不因偵探報告而動。

設計、預先登記的回溯評分與結果：[`docs/reports/phase7/detective-m0-2026-11-18.md`](../../docs/reports/phase7/detective-m0-2026-11-18.md)。
案例庫（每次跑完一列、之後回填中或錯）：[`cases.md`](cases.md)。

## 什麼時候叫起（只在互動 session）

1. **使用者點名一檔**（「幫我偵探 AXTI」）。
2. **目標或圖上鄰居的財報、長約、增資類一手剛入庫**——偵探最值錢的時候是新的一半剛出現、另一半早就在庫裡。
3. **一週看一次可開時**，挑滯留最久的 3–5 檔可開（照滯留天數，**不是分數、不是排序**——AGENTS：優先序由 lead 時間與使用者點名決定）。

**無人值守永遠不跑**：它要開強模型子代理、要主 session 核引文與寫敘事，兩件都不是排程能做的。

**成本要先說：** 一次約 30 萬 tokens、約 11 分鐘（M0 兩位實測 30.4 萬、29.2 萬）。一次只開一位；同時要跑兩檔以上先報規模再開
（記憶：大量 fan-out 先問）。回溯只在改了問句或提示之後、要量偵探準不準時跑。

## 步驟

0. **Writer lock**：`python scripts/writer_guard.py acquire --minutes 120 --purpose "偵探 <代號>"`（主 session 之後要寫敘事）。
1. **組包**：`python -m alpha detective pack <代號>`（預設寫到 `library/private/research_notes/detective/<代號>_<日期>/`）。
   讀首行計數：鄰居幾家、名冊比不到名字幾家、掃了幾份、點名幾份、對手的客戶超過上限幾份、截斷幾份。
   **鄰居 0 家或文件不到 10 份就停**——圖或庫不夠，偵探沒有材料可拼；先做研究（走圖的洞、讀一手），不要叫模型「想深一點」（L18）。
2. **派工**：Agent 工具，`subagent_type: general-purpose`、`model: fable`、`effort: high`、背景跑。提示＝`PROMPT.md` 全文，
   前面加一行「對外請求不帶 email、不帶個人資訊；本任務不需要對外」（記憶：派工提示必寫不帶 email）。
   PROMPT.md 已寫死鐵則：只讀清單、唯讀、不對外、不看價格、逐字引文附「檔名:行號」、推一步要標、四個抽屜窗口提早關至少一條、
   不給目標價與排序。**不要在 skill 或對話裡另抄一份提示**——唯一一份在 `alpha/detective.py` 的 `PROMPT_TEMPLATE`（L16）。
3. **存回報**：子代理的回報到了，主 session 把全文存成同資料夾的 `REPORT.md`（M0 實測：子代理的輸出檔可能是空的，回報文字要自己存）。
   等的時候可以做別的研究，不要停在那裡等。
4. **核引文**：`python -m alpha detective verify <包>/REPORT.md --pack <包>`。
   - `原文沒有`、`檔不存在` → 那條線索整條不用（exit code 1）。
   - `行號偏` → 人看一眼那一段，對了才用。
   - `清單外` → 子代理讀了包外的檔（M0 現況那位讀過一次）：引文對的話可用，但記進案例庫的「越界」欄。
   - 沒有引號包著的引用不核——推論鏈裡指回引文的那幾步，主 session 自己對。
5. **寫進敘事**（照 `skills/research-drain` 段 5 的寫入流程：spec → `alpha brief-check` → `alpha brief --add`；事實句補錨點）：
   - 核過的線索寫進敘事的量級那一格（②單價／量、③供給時鐘；2026-11-18 起獨立一格），句中標「偵探」與日期、推一步照標；
     「共識寫進去了沒」那一句要指得回共識數字（Engine C）——**不寫價格、不寫目標價**（Q3W 規則：寫之前不看價格）。
   - **每條寫進去的線索登一條 watch**：偏多的寫成加碼條件（`confirm[]`），偏空的寫成反證（`disproof[]`），三件套齊（L7）。
     到期是重問不是丟（INV-2）。
   - 判斷、候選狀態、其他格不因偵探報告改；要改是另一件研究，照原本的門。
   - 名單內的代號換版要補 Q3W 裁決行（`docs/reports/phase7/cases.md`）。
6. **想要的文件**：回報最後一段「想要但庫裡沒有的文件」——公開的自己抓（source-trace）；要使用者帳號的（券商報告、付費逐字稿）
   照 source-trace「開口要」鑄 `source_trace_review`，寫清楚 App、搜尋字、日期區間。
7. **案例庫**：在 [`cases.md`](cases.md) 加一列（日期、代號、現況或回溯、線索數、引文核對、越界、寫進敘事幾條、登了哪些 watch）。
   之後那些 watch 醒來被判定時，回填「中／錯／未決」——**偵探準不準只由這一欄量**，不由「跑了幾次」「找到幾條」量（L14：會隨我們多跑一次而單調上升的數字不算）。
8. **放鎖**：`python scripts/writer_guard.py release`。

## 回溯（量偵探用，不是日常）

`python -m alpha detective pack <代號> --as-of <日期>`：只收那天以前發布的文件（發布日不明的不收、晚於回溯日的不收，兩個都數出來；
INV-6、INV-3），我們寫的節錄檔拿掉 NOTE／取得日／自己的評語與提到回溯日之後日期的行（**刻意偏保守**：原文裡的未來合約期間也一起拿掉，
回溯分數寧可偏低不可虛高），鄰居只留回溯日當時就有來源的（圖上的邊至少一份來源文件早於回溯日），不給敘事。
**評分標準要在回報之前寫好登記**（M0 做法：先 commit 評分表再看回報）。

回溯當證據有三個限制（使用者 11-18 問「回測看得夠長嗎」）：模型記得訓練資料截點（約 2026 年中）以前發生的事，提示叫它「當作不知道」擋不住；
共識快照 2026-09-07 才開始存；庫是事後挑的。

**起漲點前看**（plan [`2026-11-18-001`](../../docs/plans/2026-11-18-001-dev-detective-backtest-plan.md)；設計、先登記的評分、amendment 都在那裡）：
1. `python -m alpha detective rallies`——主題等權組成員（Q3W 名單外）裡找「半年內 2 倍的起點」與同期沒漲的對照，**封存**；
   只印計數。封存檔（`backtest/cases_sealed.json`）主 session 不讀——裡面寫著誰是贏家。
   ⚠ **遮名組 2026-11-19 使用者「關吧」關閉**（清淨組看不出分辨，記憶份量不進結論）；`--group masked`／`--mask` 的機制留著，不再接續。
2. `python -m alpha detective next --group clean|masked`——照封存順序給下一個案例（不說是贏家還是對照）＋接下來三條命令：
   `backfill <編號>`（目標與當時直接鄰居回溯日前 12 個月的 EDGAR／MOPS 申報）→ `pack <代號> --as-of <日> --case <編號> [--mask]`
   （遮名組加 `--mask`：目標與鄰居換成公司A／B、中文名本體換成〔A〕，殘留不是 0 就不寫 PROMPT）→ 照組包印的門檻 `mark <編號> --pass|--fail`。
   **組完遮名包人工抽查一次**：在包裡搜目標的中文名、英文舊名、子公司名——名冊沒登的寫法殘留掃描看不到（漏了就補名冊別名）。
3. 派工照上面步驟 2（包在 `backtest/<編號>/name|mask/`，路徑不含代號）；回報存同資料夾 `REPORT.md` → `verify` → `tally`（抽屜×信心、偏多強度）。
4. 事實評分（每條高、中信心線索照「驗證」欄找回溯日之後的一手：命中／部分／沒有／未到／查不到）**在開封之前做**。
5. 一組做完才 `python -m alpha detective score --group <組>` 開封：標籤、超額（對主題等權組與大盤，3／6／12 個月）、配對分辨。
   **印了就是看過價格**：研究日誌列出這些代號，之後寫它們的敘事要在核對紀錄寫「看過回溯結果」。
6. 一列進 [`cases.md`](cases.md) 的回溯段。成本照上面：一次一位、約 30 萬 tokens；第二批開跑前問使用者。

## 不做的事

- 不入圖、不鑄 pq2、不寫 Engine C、不動 thesis、不碰 live——偵探只產生 A3 研究判斷的輸入。
- 不給目標價、價格區間、報酬率、買賣建議、跨公司排序；不給尺寸。
- 不看價格與市場資料（提示禁止開 `library/private/app`、`engine_c`、`*.db`、`docs/reports`、券商報告資料夾）。
- 不對外連線；子代理的任何請求不帶 email。
- 不把偵探報告本身當證據寫進圖——它引用的一手才是證據，而且照圖的寫入紀律走。

## 精進怎麼量

- 案例庫每季數一次：寫進敘事的偵探線索，watch 判定「中」「錯」「未決」各幾條；錯的線索裡標「高」信心的幾條。
- 機械組包的覆蓋：拿一次手組清單（或使用者指出的漏網文件）對 MANIFEST，漏的是哪一類（圖上沒邊、名冊少了名字、日期抽不出），
  修在那一類的 SSOT（圖、名冊、sidecar），不在偵探裡另寫例外（L16）。
