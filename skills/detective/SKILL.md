# Detective Skill（偵探：蒐證、拼線索、落帳）

## 定位一句話

**還能漲的只剩計畫以外的東西**（使用者 2026-11-17）；共識大致等於「照計畫走」的路徑，所以偵探找的是
**兩份不同當事人的文件放在一起才看得出來**的事——買方的擴產＋賣方的合約、買賣兩方各寫一半的金額與數量、
設備商的訂單＋公司的資本支出。M0（AXTI，2026-11-18）最有用的線索就是這樣來的：AOI 的 10-Q 寫金額、雲南鍺業的公告寫片數，
合起來是 2027 年 4 吋每片約 1,080 美元——兩邊都不是 AXT 自己的文件，而共識裡沒有漲價。

偵探的回報是**研究判斷（A3）的輸入，不是判定**：LLM 可以解析與提議，不可以授權（L15）。寫進敘事的每一句由主 session
核過原文、照既有寫入流程落地；候選狀態、判斷、門都不因偵探子代理的回報而動。

**分工（使用者 2026-11-26 定案）：偵探＝蒐證＋拼線索＋落帳；故事頁（[`skills/stock-story`](../stock-story/SKILL.md)）＝呈現。**
故事頁的問題清單（先分類八問＋十二題）是兩份 skill 共用的契約：偵探照它蒐證，故事頁照它寫。
決定紀錄：[`docs/brainstorms/2026-11-25-story-question-list-goal.md`](../../docs/brainstorms/2026-11-25-story-question-list-goal.md) §9.2。

設計、預先登記的回溯評分與結果：[`docs/reports/phase7/detective-m0-2026-11-18.md`](../../docs/reports/phase7/detective-m0-2026-11-18.md)。
案例庫（每次跑完一列、之後回填中或錯）：[`cases.md`](cases.md)。

## 兩種叫法

| 使用者說 | 做哪幾段 | 產出 |
|---|---|---|
| 「偵探 <代號>」 | B 內勤拼線索 → 線索寫進敘事、登 watch | 敘事的量級段、watch |
| 「做深 <代號>」（個股頁上的按鈕複製的就是這一句） | A 外勤蒐證 → B 內勤拼線索 → C 落帳 → D 蒐證包 → 交給 `skills/stock-story` 寫故事頁 | 蒐證包、節錄、線索、敘事換版、watch |

## 什麼時候叫起（只在互動 session）

1. **使用者點名一檔**（「幫我偵探 AXTI」「做深 Aehr」）。做深只由使用者點名，不排進 research-drain。
2. **目標或圖上鄰居的財報、長約、增資類一手剛入庫**——偵探最值錢的時候是新的一半剛出現、另一半早就在庫裡。
3. **一週看一次可開時**，挑滯留最久的 3–5 檔可開（照滯留天數，**不是分數、不是排序**——AGENTS：優先序由 lead 時間與使用者點名決定）。

**無人值守永遠不跑**：它要開強模型子代理、要主 session 核引文與寫敘事，兩件都不是排程能做的。

**成本要先說：** 內勤一次約 30 萬 tokens、約 11 分鐘（M0 兩位實測 30.4 萬、29.2 萬）。一次只開一位；同時要跑兩檔以上先報規模再開
（記憶：大量 fan-out 先問）。外勤是主 session 自己讀，量看這一檔有多少一手。回溯只在改了問句或提示之後、要量偵探準不準時跑。

## A. 外勤蒐證（做深才做；主 session 自己做，全程不看股價）

先讀 `skills/stock-story` 的問題清單，用自家庫把「先分類」八問答成草稿：**答不出的格子就是這一檔要查的東西。**
然後照下面的順序查（順序固定；每一步都記「查了什麼、在哪裡查、結果」，查不到的也記）：

1. **自家庫**：現行敘事、讀圖、brief、`library/raw`、`thesis/`、`docs/reports/`（反方與內部人買賣在這裡）。
   共識與分析師家數讀 `python -m briefing alpha-card <代號>` 的共識一節（只到今年與明年兩個年度）。
   這一檔之前的偵探回報（`library/private/research_notes/detective/<代號>_*/REPORT.md`）與個股頁物化檔
   （`library/private/app/analyst_view/<代號>.json`：圖上的位置、三題、已登記的等待）也在這一步讀——
   Aehr 第 1 版沒讀這兩樣，漏了買方預付款的金額，「哪幾條等待已登記」也寫錯。
2. **公司一手**：年報全文、最近一季財報、法說簡報（圖片檔逐頁看）、公司自己的重訊。年報的研發段、訂單段搜「訂單」「客戶」「專利」。
3. **買方端一手**：買方的重訊、年報、法說裡點名它或它這一站的話。台股設備商與供應商：買方重訊「取得機器設備」逐筆加總
   （同一相對人達門檻才申報；「一年內累計」只取最後一次；疑似重複申報給區間；相對人是子公司的要併）。
   買方沒有名字時不猜：列公司自己給的線索並標明是線索；改查買方所在地的申報（例：封測廠的設備重訊），寫出查了幾家、幾則、結果。
4. **對手端一手**：同一站對手自己的文件（招股書、年報的可比公司段與競爭段、訴訟段）——它怎麼比主角、單價與毛利率往哪走、
   專利官司誰贏。「贏的原因」與「成立了卻不是它」最硬的反證常在這裡。
5. **技術文件（賣方以外）**：每條決定賭注的岔路，兩邊各至少一份。去處：技術媒體的報導（看被引述的人各是哪一家、賺哪一種錢）、
   研討會簡報（PDF 抽字讀全文）、買方聯名的白皮書、同一站別家的產品頁與自己寫的技術文章（標明是廠商自己寫的）。
   要找到的是卡住的物理關卡與它的數字，不是誰比較樂觀。讀取工具轉述回來的引文，回原頁逐字核過才加引號。
6. **媒體與第三方**：標等級；抓不到原文的只算搜尋摘要。內部人買賣（持股含信託與配偶名下）、放空與看空報告也在這一步找。
7. **付費來源**（X 上的搜尋、付費報告）：要使用者點頭並給金額；沒搜就在蒐證包寫「沒搜」。

蒐證的規矩：

- **不看股價。** 蒐證中不開價格、不查漲跌（Q3W 規則：寫之前不看價格）。股價與「市場知道了嗎」的反應表，是 `skills/stock-story`
  在蒐證包定稿之後才抓的。
- **對外請求不帶信箱與專案名**；臨時抓取自己組標頭，用通用的 client 名稱。下載的檔各放一個新的空資料夾，讀它的 Python 用 `-I`。
- **新讀的一手當場存節錄**進 `library/raw/`（照庫裡既有節錄檔的寫法：網址、發布日、取得日、逐字段落；我們自己寫的字標 NOTE；
  追源規則在 `skills/source-trace`）。內勤的線索包只掃得到庫裡的檔，沒存的等於沒讀。券商原文不進 repo。
- **拿不到的開口要**：照 `AGENTS.md`「向你要文件」那一區——列文件、為什麼、哪裡拿、替代，鑄 `source_trace_review`；不默默略過。
- 「沒讀」和「沒公布」分開記；「我找不到」和「它不存在」是兩個 claim（L11）——一句話在一份檔找不到，先搜其他檔再寫「沒有」。

## B. 內勤拼線索（「偵探 <代號>」只做這一段）

0. **Writer lock**：`python scripts/writer_guard.py acquire --minutes 120 --purpose "偵探 <代號>"`（主 session 之後要寫敘事）。
1. **組包**：`python -m alpha detective pack <代號>`（預設寫到 `library/private/research_notes/detective/<代號>_<日期>/`）。
   讀首行計數：鄰居幾家、名冊比不到名字幾家、掃了幾份、點名幾份、對手的客戶超過上限幾份、截斷幾份。
   **鄰居 0 家或文件不到 10 份就停**——圖或庫不夠，偵探沒有材料可拼；先做研究（走圖的洞、讀一手），不要叫模型「想深一點」（L18）。
2. **派工**：Agent 工具，`subagent_type: general-purpose`、`model: fable`、`effort: high`、背景跑。提示＝`PROMPT.md` 全文，
   前面加一行「對外請求不帶 email、不帶個人資訊；本任務不需要對外」（記憶：派工提示必寫不帶 email）。
   PROMPT.md 已寫死鐵則：只讀清單、唯讀、不對外、不看價格、逐字引文附「檔名:行號」、推一步要標、四個抽屜窗口提早關至少一條、
   不給目標價與排序。**不要在 skill 或對話裡另抄一份提示**——唯一一份在 `alpha/detective.py` 的 `PROMPT_TEMPLATE`（L16）。
3. **存回報**：子代理的回報到了，主 session 把全文存成同資料夾的 `REPORT.md`（M0 實測：子代理的輸出檔可能是空的，回報文字要自己存）。
   等的時候可以做別的研究，不要停在那裡等。
4. **核引文**：`python -m alpha detective verify <包>/REPORT.md --pack <包>`。
   - `原文沒有`、`檔不存在` → 那條線索整條不用（exit code 1）。
   - `行號偏` → 人看一眼那一段，對了才用。
   - `清單外` → 子代理讀了包外的檔（M0 現況那位讀過一次）：引文對的話可用，但記進案例庫的「越界」欄。
   - 沒有引號包著的引用不核——推論鏈裡指回引文的那幾步，主 session 自己對。
5. **寫進敘事**（照 `skills/research-drain` 段 5 的寫入流程：spec → `alpha brief-check` → `alpha brief --add`；事實句補錨點）。
   做深時這一步併進 C 的敘事換版，只換一版：
   - 核過的線索寫進敘事的量級那一格（②單價／量、③供給時鐘；2026-11-18 起獨立一格），句中標「偵探」與日期、推一步照標；
     「共識寫進去了沒」那一句要指得回共識數字（Engine C）——**不寫價格、不寫目標價**（Q3W 規則：寫之前不看價格）。
   - **每條寫進去的線索登一條 watch**：偏多的寫成加碼條件（`confirm[]`），偏空的寫成反證（`disproof[]`），三件套齊（L7）。
     到期是重問不是丟（INV-2）。
   - 判斷、候選狀態、其他格不因偵探子代理的回報改；要改是另一件研究，照原本的門。
   - 名單內的代號換版要補 Q3W 裁決行（`docs/reports/phase7/cases.md`）。
6. **想要的文件**：回報最後一段「想要但庫裡沒有的文件」——公開的自己抓（source-trace）；要使用者帳號的（券商報告、付費逐字稿）
   照 `AGENTS.md`「向你要文件」那一區鑄 `source_trace_review`，寫清楚 App、搜尋字、日期區間。
7. **案例庫**：在 [`cases.md`](cases.md) 加一列（日期、代號、現況或回溯、線索數、引文核對、越界、寫進敘事幾條、登了哪些 watch）。
   之後那些 watch 醒來被判定時，回填「中／錯／未決」——**偵探準不準只由這一欄量**，不由「跑了幾次」「找到幾條」量（L14：會隨我們多跑一次而單調上升的數字不算）。
8. **放鎖**：`python scripts/writer_guard.py release`（做深時留到 D 做完才放）。

## C. 落帳（做深才做；在寫故事頁之前做完）

故事頁寫到的東西，系統要先知道。順序：

1. **節錄點名**：A 讀的每一份——存了節錄的列檔名，只看到搜尋摘要的標明，付費來源沒搜的寫「沒搜」。
2. **圖的洞登記成線索**：故事要用、圖上沒有的層或邊，每一份撐得住它的文件登記一條——
   `python -m engine_b.cli register --source "directed:detective_<代號>_<日期>" --url <網址> --title <標題> [--published-at <日期>]`。
   之後照舊走 pq1 → 入圖包 → 人工 `go`；偵探不入圖，也不因為故事需要就催入圖。
3. **敘事換版**（一版；寫入流程同 B5）：偵探線索寫進量級段；蒐證讓哪一格的事實變了就改哪一格。
   讀到的新一手讓判斷站不住時，照 research-drain 的敘事重寫流程改判——那是研究，照原本的門，不是偵探回報的權限。
4. **等待登記**：「什麼會讓夢醒」寫成反證、「再一次要看的」寫成加碼條件或對帳日，寫下即登記 watch、每條有到期（INV-2、L7）。
   已登記的等待被這次蒐證碰到的，照 `python -m engine_b.event_watch semantic-queue` 判；來不及判的在蒐證包標「碰到、還沒判」。
5. **短故事跟著換版**：敘事一換版舊的短故事就過期——照 research-drain「故事」段重寫（`python -m alpha stories --check`／`--add`）。
6. **案例庫與 Q3W 裁決行**：同 B5、B7。

## D. 蒐證包（做深才做）

把 A 到 C 的結果寫成一份 `EVIDENCE.md`，放在線索包同一個資料夾（私有、不進 repo）；骨架是 [`EVIDENCE_TEMPLATE.md`](EVIDENCE_TEMPLATE.md)。
它是故事頁唯一的輸入清單：十二題每一題有哪些證據（檔名與行號、來源等級）、哪些查不到（查了什麼）、圖的洞（線索 id）、
等待（哪幾條已登記、id 與到期；哪幾條還沒）。**蒐證包定稿之後才抓股價、才動筆**——接著照 `skills/stock-story` 做。

回報給使用者的（做深的前半段收尾）：一句話結論、十二題各自有沒有證據、最大的洞、落了哪些帳（敘事版本、watch 幾條、線索幾條）、還沒做的。

## 回溯（量偵探用，不是日常）

`python -m alpha detective pack <代號> --as-of <日期>`：只收那天以前發布的文件（發布日不明的不收、晚於回溯日的不收，兩個都數出來；
INV-6、INV-3），我們寫的節錄檔拿掉 NOTE／取得日／自己的評語與提到回溯日之後日期的行（**刻意偏保守**：原文裡的未來合約期間也一起拿掉，
回溯分數寧可偏低不可虛高），鄰居只留回溯日當時就有來源的（圖上的邊至少一份來源文件早於回溯日），不給敘事。
**評分標準要在回報之前寫好登記**（M0 做法：先 commit 評分表再看回報）。

回溯當證據有三個限制（使用者 11-18 問「回測看得夠長嗎」）：模型記得訓練資料截點（約 2026 年中）以前發生的事，提示叫它「當作不知道」擋不住；
共識快照 2026-09-07 才開始存；庫是事後挑的。

**起漲點前看**（plan [`2026-11-18-001`](../../docs/plans/2026-11-18-001-dev-detective-backtest-plan.md)；設計、先登記的評分、amendment 都在那裡）：
1. `python -m alpha detective rallies`——主題等權組成員（Q3W 名單外）裡找「半年內 2 倍的起點」與同期沒漲的對照，**封存**；
   只印計數。封存檔（`backtest/cases_sealed.json`）主 session 不讀——裡面寫著誰是贏家。
   ⚠ **遮名組 2026-11-19 使用者「關吧」關閉**（清淨組看不出分辨，記憶份量不進結論）；`--group masked`／`--mask` 的機制留著，不再接續。
2. `python -m alpha detective next --group clean|masked`——照封存順序給下一個案例（不說是贏家還是對照）＋接下來三條命令：
   `backfill <編號>`（目標與當時直接鄰居回溯日前 12 個月的 EDGAR／MOPS 申報）→ `pack <代號> --as-of <日> --case <編號> [--mask]`
   （遮名組加 `--mask`：目標與鄰居換成公司A／B、中文名本體換成〔A〕，殘留不是 0 就不寫 PROMPT）→ 照組包印的門檻 `mark <編號> --pass|--fail`。
   **組完遮名包人工抽查一次**：在包裡搜目標的中文名、英文舊名、子公司名——名冊沒登的寫法殘留掃描看不到（漏了就補名冊別名）。
3. 派工照 B 的步驟 2（包在 `backtest/<編號>/name|mask/`，路徑不含代號）；回報存同資料夾 `REPORT.md` → `verify` → `tally`（抽屜×信心、偏多強度）。
4. 事實評分（每條高、中信心線索照「驗證」欄找回溯日之後的一手：命中／部分／沒有／未到／查不到）**在開封之前做**。
5. 一組做完才 `python -m alpha detective score --group <組>` 開封：標籤、超額（對主題等權組與大盤，3／6／12 個月）、配對分辨。
   **印了就是看過價格**：研究日誌列出這些代號，之後寫它們的敘事要在核對紀錄寫「看過回溯結果」。
6. 一列進 [`cases.md`](cases.md) 的回溯段。成本照上面：一次一位、約 30 萬 tokens；第二批開跑前問使用者。

## 不做的事

- 不入圖、不鑄 pq2、不寫 Engine C、不動 thesis、不碰 live——偵探只產生 A3 研究判斷的輸入；圖的洞只登記成線索。
- 不給目標價、價格區間、報酬率、買賣建議、跨公司排序；不給尺寸。
- 不看價格與市場資料：外勤不查股價；子代理的提示禁止開 `library/private/app`、`engine_c`、`*.db`、`docs/reports`、券商報告資料夾。
- 子代理不對外連線；主 session 的對外請求與子代理的任何請求都不帶 email。
- 不把偵探報告本身當證據寫進圖——它引用的一手才是證據，而且照圖的寫入紀律走。
- 不寫故事頁：呈現、冷讀、存進 APP 是 `skills/stock-story` 的事。

## 精進怎麼量

- 案例庫每季數一次：寫進敘事的偵探線索，watch 判定「中」「錯」「未決」各幾條；錯的線索裡標「高」信心的幾條。
- 機械組包的覆蓋：拿一次手組清單（或使用者指出的漏網文件）對 MANIFEST，漏的是哪一類（圖上沒邊、名冊少了名字、日期抽不出），
  修在那一類的 SSOT（圖、名冊、sidecar），不在偵探裡另寫例外（L16）。
- 蒐證夠不夠：故事頁交稿時自評標「一半」「答不到」的題，回頭對蒐證包——是沒查、查不到、還是查到了沒寫。沒查的那一類補進 A 的順序。
